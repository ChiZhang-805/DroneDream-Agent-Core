# 全图 3D UAV Corridor 契约

## 数据流

已绑定地图碰撞语义 + 当前机型包络 + 偏好 → `PreferredAirspace`。
同一实现提供全图透明体积、位置高度层、软偏离代价和楼梯地面梯度。
地图解释缓存保留语义地点、连接、几何库存与限制；任务准备把实际资产对的
高度样本送入 Harness 输入。LLM 理解地点用途、任务阶段和例外理由，几何工具求解。
运行时逐拍上下文及训练记录加入空间绑定；局部专家仍通过已资格化路线的局部目标、
实时几何和原生飞行状态输出连续控制，不以自然语言说明冒充网络控制量。

## 软空间和硬约束

- 路线是一条线。全图空间不以任务路线或少数命名节点作为生成边界。
- 一个 XY 列保留多个楼层；逐层扣除机体半高和余量后取 40–80% 高度区间。
- 室外 5–8 m AGL 以地形为参考，不从树冠、灯柱顶端重新计高。
- 地形覆盖之外保持未知。没有地形来源的资产返回空偏好，不假造空间。
- 精细碰撞与 Runtime 保守包络取并集；门楣、楼梯台阶、家具、树冠均不删除。
- 寻路及独立路线净空复核也使用同一双层并集，不能只让空间视图避开 Runtime 独有障碍。
- 寻路冻结已校验图元并用饱和净空下界做连续线段证明；只有更优代价的候选边才做碰撞查询。
  空间桶外障碍也有保守距离下界，不能以“未选中障碍”当作无限净空。
  网格增加真实起终点的各轴坐标，避免窄门/楼梯被网格相位误判无路；ENU 原点不当作地面。
- 起飞前度量候选搜索上限 60 秒；飞行中改令仍为 8 秒。长路线规划不能直接占用实时控制周期。
- 当前列算法使用保守 AABB，旋转／曲面处可能少显示理想空间，不会因此放宽碰撞规则。
- 局部楼梯梯度只表示趋势，不替代真实台阶几何；执行仍经过速度、加速度、jerk、
  上下方覆盖、迟滞、制动、负载证据和数据时效检查。
- 偏离只改变路线代价，不拒绝取件所需的低空终点；简化阶段保留偏好成本，
  避免将求出的爬升重新抹成低空直线。
- 静态体积不是实时 ESDF，更不是 flight-ready 或真机许可。

## 接口与目录

- Core：`preferred_airspace.py`，不依赖 UI、账户、Torch 或云 API。
- App：`airspace_service.py`，双重认证的 `POST /v1/assets/preferred-airspace`。
  请求绑定地图与机型的实际内容 SHA；原始文件每次重新核验，缓存上限两份。
- 地图页面：`PreferredAirspaceView.tsx` 从此接口读实际数据；ENU Z-up，
  透明体积、保守障碍、同版本路线、高度剖切和体积数值查询。
  同时显示扣除机身半高后的最小上下净空；剖切支持负 ENU 高度，调节不重置观察角度。
  中心点模式表示体积采样点，不能称作传感器点云。旧地图的演示路线不进入此视图。
- 运行端：`runtime_depth_safety_worker.py` 每次观测记录同周期位置的软空间信息；
  已存在负载测量包络时使用更大的几何包络，未测量状态仍由硬检查拒绝。
- 核验工具：`scripts/inspect_preferred_airspace.py`，隔离解包当前签发资产，
  独立批量测试体积与膨胀障碍相交关系，输出真实构建及查询计时。

## 训练和租卡边界

现有 13,714 组正式静态视觉输入训练感知，不作为飞行控制标签。
路线进入更合理的高度带后，示范采集记录实际速度控制与动作后果；不能把建议梯度
或漂亮体积图直接当作教师执行成功。新视觉先训练、冻结、独立评价，再对连续物理
观测重新编码和训练控制专家；对错误访问做离线 DAgger 纠正，落地后再优化。
现有奖励保留独立见证的进度、成功、碰撞、提前落地、能耗、动作变化与干预，
不以进入蓝色空间替代安全成功，也不因必须低空取件而持续惩罚任务本身。
当前不改变已冻结神经网络张量宽度；空间信息通过实际路线局部目标与感知进入控制，
附加上下文另行留痕。若未来新增专用网络输入，必须新契约、重编码和重训，不能改清单骗过准入。

验收包括：多楼层、障碍空缺、地图边缘未知、资产更换、室外爬升、低空终点、
路线简化、真实资产独立几何交叉检查、认证拒绝、前端旧回包隔离和全量回归。
