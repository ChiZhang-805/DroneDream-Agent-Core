## 已落地的改变

| 问题 | 生产实现与验证 |
| --- | --- |
| 固定中心像素抽样遗漏细障碍 | 唯一深度转换路径检查全图；每块保留最近径向命中及其原像素方向。64 个图块内偏移全部保留，过去的中心点抽样数学对照仅保留 1 个。这个对照不是恢复旧生产路径。 |
| 无效深度和真实无命中混用 | 硬件默认无返回未知；只有显式 Gazebo 模式接受远裁剪语义。NaN、负无穷、过近/非法值不变成自由空间；全无效帧拒绝。 |
| 实际小图像套用大图标定 | 绑定实际尺寸、步长、R_FLOAT32 布局和完整标定摘要，换尺寸拒绝；极端内参在像素读取前拒绝。 |
| 一帧内附近射线冲刷掉刚记录的障碍 | 帧融合每体素更新一次，命中优先；新命中立即撤销历史自由许可。测试射线顺序置换和像素到地图完整链路。 |
| 重复帧虚增空闲证据 | 同一扫描不能再次提交；失败时地图、已接受帧和动态目标清除状态不变。 |
| 少量有效像素被射线数量掩盖 | 原始有效像素比例进入原始扫描、冻结帧、注册表和几何特征质量。1/64 有效像素即使产生 300 条射线，也不能获得完整质量和运动就绪。 |
| 均匀彩色画面被误判为丰富纹理 | RGB 质量和模型使用统一布局解码；检查亮度分布、邻域空间差异和曝光比例，排除 padding/alpha。质量分数不作为识别正确率。 |
| 新姿态与旧 IMU 拼出假加速度 | 位置、姿态和 IMU 的来源接收时间跨度不超过 50 ms；测试多姿态静止比力的重力补偿。 |
| 未注册必需传感器仍显示就绪 | 空必需集合明确不可运动；未知质量/覆盖默认为 0；注册和读取均隔离可变对象并重新校验。 |
| 新旧特征宽度相同被当作兼容 | 新语义进入统一特征摘要；训练、推理、装配继续严格核对内容，不改写旧包资格。 |

IMU、磁场、气压和 GNSS 的融合仍由实际 PX4 v1.16.0 承担，没有在其外部添加会重复使用相同测量的简单 EKF。没有伪造新的传感器偏置、GNSS 精度、交叉协方差或室内 VIO 能力。磁场的物理单位、安装姿态与噪声换算继续使用唯一原生实现，本次重新编译验证。

## 小实验与延迟

### 明确区分执行环境

Windows 开发解释器为仓库 `.venv/Scripts/python.exe`（Python 3.11.9）。根据 `run_pluginized_runtime_acceptance.py` 的实际启动脚本，当前开发 Runtime 入口使用：

```text
/home/dronedream/.local/share/dronedream-autonomy/v0.1.0/venv/bin/python
```

该环境为 Python 3.12.3、NumPy 2.5.2、Pillow 12.3.0、Pydantic 2.13.4。另一套 `/opt/dronedream/venv` 不是这一入口，并缺少完整管线需要的 Pillow；使用它得到的早期 `runtime-*.json` 仅作为不同环境比较保留，不能作为当前入口通过证据。没有删除旧环境、向旧环境补装依赖或修改安装目录。

### 解析正确性

固定合成深度夹具中，细障碍偏移覆盖 **64/64**，用独立针孔公式检查的最大落点数值误差约 **2.31×10⁻¹⁶ m**。这只证明同一已知理想深度的数学转换，**不是相机测距达到这个精度**。现实误差仍包含标定、视差、曝光、材质、运动和定位误差。

### 当前开发 Runtime 的投影测试

每种分辨率预热 20 次，计量 1,000 次；不关闭 GC、不移除慢帧。三种尺寸均输出 300 条有界射线。

| 输入 | P50 | P95 | P99 | 最大值 |
| --- | ---: | ---: | ---: | ---: |
| 160×120 | 1.154 ms | 1.574 ms | 27.135 ms | 33.474 ms |
| 320×240 | 1.482 ms | 1.953 ms | 24.930 ms | 33.415 ms |
| 640×480 | 3.516 ms | 4.070 ms | 31.937 ms | 39.043 ms |

**研究中设定的投影 P99 < 20 ms 优化目标未稳定通过，`acceptance_passed` 保留为 false。**不能用前一次较快的测量覆盖后一次失败，也不能将三个分辨率平均后掩盖慢帧。

### 像素到模型几何特征的完整软件段

另测 300 个独立合成捕获时刻：投影 → 扫描合同与坐标转换 → 冻结、注册和地图融合 → 几何特征。局部地图重复观测同一合成场景，测试期间完整回归仍在运行；这不是机器人动态环境基准。

| 阶段 | P50 | P99 | 最大值 |
| --- | ---: | ---: | ---: |
| 投影 | 1.337 ms | 28.445 ms | 33.226 ms |
| 坐标转换与扫描 | 1.942 ms | 33.825 ms | 37.006 ms |
| 冻结、注册与地图融合 | 4.795 ms | 34.348 ms | 39.164 ms |
| 几何编码 | 1.943 ms | 2.777 ms | 3.338 ms |
| **整段** | **10.229 ms** | **43.429 ms** | **47.811 ms** |

各阶段 P99 不能相加当作整段 P99。这个合成夹具的整段 P99 低于当前 20 Hz 周期的 50 ms，但它**未计相机渲染/采集、传输、其他模态、模型推理、控制发送**，不能据此证明整个控制环稳定达到 20 Hz。全部样本保留，功能质量检查通过。

GC 回调实测显示，整段最慢一帧 47.81 ms 中约 35.05 ms 处于垃圾回收；另外的 Windows 诊断也观察到相同机制。回调仅测量，不改变 GC 策略。Python 官方明确说明 GC 处理引用环及不同代次；直接禁用或冻结全部对象会改变内存生命周期，不能为了漂亮的延迟数字这样修改飞行端。[^gc]

### 已有图像检查的边界

只读查看了已有 `native-visual-prefetch-px4-20260909` 运行中保存的图像。抽样画面确有大面积均匀、低纹理区域，不能仅凭颜色通道不同判为丰富信息。这些文件是缩放后的模型图像，既无独立语义标签，也不是原始相机曝光，因此不把其质量统计写成原始图像准入率或视觉识别准确率。

## 当前结论

转换正确性、来源一致性、无效信息处理、地图命中保留和状态时间安全边界已经实现并通过软件回归。与原始数据相比的可量化改进是避免抽样丢障碍、错误清空、时间拼接和虚假质量；没有声称物理传感器本身变得无噪声。

投影尾延迟仍是未通过的优化项；真实相机/IMU 标定、双目深度误差曲线、语义标签评测及室内长期定位，必须使用对应设备/独立数据补证，不能从本次解析测试推出。改动未部署成安装包，未重新训练产品权重，未给历史模型包补签新资格。
