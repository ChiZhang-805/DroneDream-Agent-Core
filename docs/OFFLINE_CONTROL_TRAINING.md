# 连续控制离线学习接口

这条学习链使用与部署 ONNX 相同的输入顺序、缺失掩码、特征语义哈希和四轴动作。训练依赖通过 `local-policy-refinement` 可选依赖安装；正常飞行入口不导入 PyTorch，不在飞行中更新模型权重。

## 当前代码职责

| 模块 | 实际实现 |
| --- | --- |
| `training/flight_environment.py` | 明确的观测、动作、实际执行、验证器回执、终止/截断合同；逐步身份、顺序、原始样本与动作哈希检查；奖励计算 |
| `training/executed_control.py` | 从实际接受的纯速度传输及偏航积分记录恢复四轴标签；检查原始输入、期限和幅度，不用规划提案或位置控制前馈冒充标签 |
| `training/dagger.py` | 学生访问状态上请求教师纠正；可复现教师/学生混合采样；独立保留教师行为标签与学生原提案的反事实风险标签；留出任务拒收 |
| `training/ppo.py` | BC 初始化的离散模式与 tanh 四轴随机策略；独立价值网络；GAE、PPO 裁剪目标、KL 早停、梯度范数限制、基础行为回放约束；优化器/随机数/数据绑定检查点恢复 |
| `training/causal_policy.py` | 共享编码器、有限展开 GRU、非线性控制头、模式/四轴/辅助风险；按完整任务分组的 BC、跨角色历史、整窗源身份、ONNX 导出和严格检查点载入 |
| `training/causal_ppo.py` | 复用 PPO 优化/GAE 的因果策略适配；真实 hold 步预热、最后观测自举、历史在 reset 清空；动作头更新，整个共享表示和风险分支冻结 |
| `training/policy_packaging.py` | 三种动作专家整套原子替换；其他七角色文件哈希不变；用生产 ONNX 加载器验证完整目录后才发布目录 |
| `scripts/train_causal_control_ensemble.py` | 训练三种独立权重；训练前检查当前完整基包、视觉宽度、任务组及源泄漏；新目录写入权重/配置/分组回执，不自动激活 |
| `scripts/refine_local_policy_ppo.py` | 显式选择仿真适配器；每个 rollout 后暂停控制，再更新权重；保留轨迹回执、检查点和新 ONNX；不覆盖基座，不自动授予资格 |

PPO 初始配置冻结输入编码层和已有导航风险头，仅微调本次选定动作专家的模式头、连续控制头，并训练不随部署包分发的价值头。其他专家保持不变。一般、精细、恢复不能混在同一个专家微调任务里。PPO 的训练价值不是动作安全风险，不能替代独立风险专家。

探索噪声在 tanh 之前的潜在四轴空间采样，初始标准差显式配置为前/右/上/偏航 `[0.08, 0.08, 0.04, 0.06]`，学习范围为 `[0.01, 0.25]`，保存并核对在训练检查点中。它不是固定的物理 m/s，也不是执行噪声保证；最终动作还要经过物理映射和安全复核。相同已记录输入的只读回放显示，原固定约 0.497 的潜在标准差会把约 -0.053 的平均上升轴扰动到一次实际 -0.734 的下降提案，因此改为 BC 邻域的小幅探索。部署不携带随机采样器，基础模型的平均输出不因配置探索幅度而改变。

因果结构在 BC 中会训练编码器、GRU 和控制头；PPO 初始微调则连共享非线性 trunk 一并冻结，避免只冻结风险输出层、其上游仍变化而导致风险漂移。导出只含部署策略，不含价值头、探索噪声和优化器。当前 `refine_local_policy_ppo.py` 只接受显式 `--architecture causal-gru-control`，读取严格绑定特征合同的 `.pt` 与对应训练收据；已移除旧前馈命令行路径，不能依据旧说明把 ONNX 或旧权重当作当前检查点。

两个因果 BC 入口均导出真实的本角色回放与冻结留出数据。PPO 必须提供基座的
`--base-training-receipt`、`--training-replay`、`--validation-replay`、
`--training-observations`、`--validation-observations` 和 `--stream-groups`。
五个数据文件按训练收据逐字节核验，不能只提供文件名相近的另一批数据。
分组清单包含原始路线内容与哈希，使用地图/三维空间线段覆盖而非任务名称；
同路线改名、往返、环路换起点或改变共线采样不能进入不同集合。
基座已训练过的路线不能在微调时改称验证集；PPO 在启动仿真前排除验证路线，
恢复优化器还必须匹配原回放、留出与环境上下文。BC 与 PPO 共用冻结评估器，
输出各模式和每轴正/负/近零覆盖；缺失类别不是满分。评估不触发自动晋级。

默认因果窗口为 16 次独立观测。启动的不足窗口不计作普通飞行样本；PPO 用有回执的 hold 步积累历史，无法获得连续观测或预热时任务已经终止就拒绝训练。训练和准入按全部观测推进历史，再选择相应动作角色评估，不能先过滤专家而抹掉其他专家刚控制过的传感器历史。验证泄漏检查覆盖整个窗口的来源，而不仅检查最后一帧。

历史行额外包含真实源间隔（除以 250 ms）；首帧/重置为零，重复帧不推进。16×939 的历史张量和掩码有独立语义哈希；检查点、ONNX 元数据、包清单及加载器都检查该哈希。输入编码及 GRU 在 BC 中学习时间变化，不把 20 ms 和 200 ms 的观测间隔视为相同。普通 Runtime 仅使用 ONNX，不携带训练框架。

DAgger 的学生提案、教师纠正、经安全层允许的实际动作是三种不同的数据。风险标签必须明确绑定被评估的原动作及独立几何或物理反事实回执；没有该证据就不生成风险标签。禁止把教师的安全替代动作写成学生原提案。

教师数据入口现要求任务证据绑定 `runtime-state/control-applications.jsonl`。旧安全历史仅包含建议速度，并不能证明执行器发送过相同控制；这种记录不再接受为连续示范。`position-velocity-ned` 的速度前馈也不等于速度控制标签。偏航必须有发送时实际采用的前一航向、角速度和积分间隔，与最终发送航向一致，不能因旧记录缺字段便填写零值。

教师内部的短路径目标不得替换原始观测里的任务目标。标签转换使用部署输入声明的同一速度/偏航范围，超范围拒收而非裁剪；已成功飞行的动作示范不自动变成独立反事实风险标签。

## 原生示范采集与数据集

`run_school_map_depth_qualification.py --training-data-collection --teacher-observation-collection` 使用显式仿真教师和独立观测记录器，不加载云端或本地策略替教师出标签。视觉采集使用 `--local-navigation-visual-enabled --learning-image-size 224 128`；图像大小允许在各轴 64–1024 范围内配置。后台只允许一个待处理观测，不积压过期控制；关闭时检查写入排空和记录数量，异常不能报告采集成功。

`scripts/build_executed_policy_dataset.py --training-run <完整任务目录> --validation-run <独立完整任务目录> --output <新目录>` 核验仿真门槛、文件哈希、观测、实际传输、期限和视觉来源，生成训练/验证 JSONL、任务分组及数据收据。两个任务参数可重复。相同物理来源、地图/空间路线组及视觉来源不能跨集合；换车辆不制造独立路线。未发送、被安全覆盖或使用位置前馈的动作不伪装成连续示范。

生成的视觉输入保留实际 PNG 和像素哈希，尚未编造视觉特征；随后用 `encode_local_policy_visual_features.py` 与真实视觉编码器产生特征，再进入因果 BC。示范中的成功动作辅助风险标签不具备反事实意义，不能替代独立动作风险专家的训练集。几何专用采集必须显式选择 `--geometry-only`。

原生定位协方差允许 PX4 只报告已测得的对角项、将交叉项标为未知。未知值保留为 null；位置对角项缺失仍拒收。相关性未知时使用位置方差之和作为保守上界，不假设独立，也不填零精度。这个输入语义属于当前特征合同，旧权重/数据必须重新核验而非改名。

完整因果策略包的 `training-lineage.json` 使用现有训练保留收据合同，绑定源包、目标包、车辆/传感器/地图、七个保留专家和三个替换控制专家的哈希。准入器实际核对未变输入与原准入收据，仅允许继承字节相同且语义相同的专家证据；三个新策略必须重新评估，装包本身不授予仿真资格。

## 仿真适配器合同

数据集同时输出 `training-observations.jsonl`、`validation-observations.jsonl`，保存所有通过来源核验的独立观察；动作标签仍只来自已执行回执。因果训练通过 `--training-observations` / `--validation-observations` 接入完整历史，不以虚构标签补齐窗口，也不因未执行提案而丢失真实观察。历史与标签的来源、时间、输入逐项核对，训练/验证之间连未标注历史也不能泄漏。PPO 的 `--training-observations` 对重放缓冲采用同一规则。

`train_causal_control_role.py` 允许为实际仿真开发训练单独一个新专家，不复用旧导航权重或伪装成完整专家包；完整包仍经 `train_causal_control_ensemble.py` 的三个控制角色与其余专家检查。图像数据集编码和实时推理现在共用 `forward_rgb_tensor`，并以相同 PNG/原始 RGB 张量的逐值测试约束预处理一致性。

PPO 与 DAgger 的库级采集函数现已在成功、预热失败、输入异常和中途终止时统一执行 `quiesce`，不再仅依赖 CLI 的善后代码。真实仿真适配器缺少该方法会在 reset 前被拒绝；停控失败不会向优化器返回成功 rollout。DAgger 最后一步结束时不再额外启动一个无人控制的新 episode。

`FlightTrainingEnvironment` 接收 `PilotAction`，返回 `FlightStep`。其中必须包含真实的下一时刻观测、实际发送的动作与指令摘要、独立任务验证器给出的结果。命令行要求适配器明确声明 `simulation_only=True`、`evidence_kind=px4-gazebo`，并实现 `reset`、`step`、`quiesce`、`close`。

实际适配器工厂为 `dronedream_agent_core.training.px4_environment:create_environment`，由 `--environment-factory` 和 `--environment-config` 显式配置，运行在 Linux/WSL 仿真主机。reset 校验六份资产哈希并启动现有原生传感器任务进程；step 通过本地、有期限且绑定来源的通信传入模型动作，等待已有执行器的实际接受回执，再取得新的传感器观测。quiesce 撤销后续模型回复、请求安全落地并等待 PX4 原生落地凭据。不会自动切换成无物理环境，也不把此入口授予的训练权限当作产品飞行准入。

运行侧使用独立的 `SimulationTrainingTrace`，记录实际学习器权重身份和动作来源，不构造部署专家的分数、风险或准入收据。悬停回执同时记录实际 NED 位置目标；不能把位置保持的零速度前馈伪装成纯速度策略。普通模型调用和旧纯速度回执的序列化身份保持不变。

`LocalPolicyObservation` 只包含输入；BC/DAgger 有独立核验标签后才生成 `LocalPolicyTrainingSample`。实时训练不用填假动作或风险占位。相机使用共享 RGB 预处理函数与单独加载的冻结视觉编码器，不装入历史导航权重。独立 Gazebo 位置只进入结果验证器，不进入学生输入。该适配器代码仍须通过实际学习器闭环运行验证，不能由通信或数学单测代替。

观测使用当前部署合同；旧合同、缺失原始时间/来源、重复样本、跨任务/地图跳变、没有报告的安全替换都会报错。外部时间截断使用最后观测的价值进行自举，但不把重置后的新任务接到上一任务的优势计算里；失败或成功终止不自举。该处理遵循 [Gymnasium 的时间限制语义](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)。PPO 实现依据 [原论文](https://arxiv.org/abs/1707.06347)，学生状态上的教师聚合依据 [DAgger 原论文](https://proceedings.mlr.press/v15/ross11a.html)。

## 奖励和防作弊

进展使用验证器实测位置至当前阶段目标的距离势函数 `goal_distance_m`，不是模型自己声称的完成度，也不将直线距离声称为已求解的可飞走廊长度。每个阶段/目标修订记住最小已到达距离，往返不能重复领取进展；切换目的地重置当前比较，不平白获得奖励。阶段事件仅奖励一次。碰撞、越界、失控和提前落地必须失败终止，当步取消进展与完成奖励。独立结果验证使用车辆体积、位置序列和保守扫掠净空，而不只检查两个端点。

实际 PX4 电流读数为不可用值时，能耗为 `null`，不是零。正能耗奖励系数会拒绝这种观测；必须显式通过 `--reward-config` 设置当前不支持的能耗项为零，不能静默训练出虚假的节能效果。后续取得有效功率遥测后才启用该目标。

规定等待时间不收普通怠速罚分，但仍计算实际能耗。安全干预单独记录并扣分；即便实际动作被替换，策略概率仍针对原提案计算，不把替代动作冒充策略采样。最终晋级仍须独立检查安全干预比例和真实任务表现。

实际位置控制的重新规划/制动结果使用 `SafetyPositionControl` 保存 NED 位置目标、速度前馈和航向，不转换成 `PilotAction` 四轴标签，也不能不报安全干预。纯速度模型动作仍严格核对原始输入与实际接受时间；重新规划的位置控制也有独立发送预算和接受期限。只有已确认的零速度安全悬停可以晚于旧模型提案期限记录为安全接管，不能据此续期模型运动。

原生训练的控制变化成本使用实际 NED 速度前馈差（按水平/垂直速度范围归一化）和最短航向差（除以 180°）的平方和。它不声称是位置误差、模型杆量或电机能耗；第一份回执建立基线，不假定先前发送过零值。转场证据显式标明此度量。

## 验证边界

算法测试检查导出 ONNX 与训练动作输出一致、检查点恢复后随机采样和优化结果可复现、提前落地与循环进展不能刷奖励、学生/教师/实际动作不混标。这些测试不证明长任务飞行成功。物理采样和权重训练必须另有完整任务、原生遥测、控制发送与验证器证据，并经过现有模型准入和产品装载流程。
