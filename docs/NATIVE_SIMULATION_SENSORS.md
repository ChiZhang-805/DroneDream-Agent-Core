# 原生仿真传感器与安装边界

本模块修正的是仿真传感器的物理场和传输合同，不是给策略提供无噪声真值。策略继续读取 PX4 原生 NED 状态、IMU、定位质量以及实际相机/深度流；不使用 Gazebo 姿态拟合飞控航向。

## 磁力计

当前绑定的 PX4/Gazebo Harmonic bridge 将 `field_tesla` 消息按历史 gauss 线协议解码。Gazebo 原磁力计与飞控的地磁表/坐标假设不一致，会产生航向偏差；不能靠放宽身份误差、把真值角度塞进策略，或反复覆盖飞控自动保存的偏角解决。

`native/gazebo_sensors` 使用当前 Runtime 的 PX4 地磁表计算 ENU/tesla 磁场，Gazebo 原生传感器仍负责安装姿态、采样频率和噪声。已绑定车辆的 Harmonic 噪声幅度由 gauss 转换为 tesla，动态噪声相关时间不缩放。原始测量另发到诊断 topic；PX4 topic 只由这一实现发布，显式转换为该 bridge 的历史线协议。地理位置和世界姿态只用于仿真传感器本身，与普通物理传感器模拟用途相同，不进入策略的隐藏输入。

运行时生成独立 `server.config`，不改安装目录、PX4 源码、世界 SDF 或用户资产。收据分别记录世界声明的静态磁场和实际启用的地理磁场，不把替换后的场谎称为原静态值。当前实现要求地图为北向 ENU；其他约定明确拒绝，而不是猜测轴向。

## 编译与资源封装

在具有匹配 PX4 源码和 Gazebo Harmonic 开发依赖的 Linux/WSL 中运行：

```text
python scripts/build_native_sensor_runtime.py --px4-root <匹配的PX4源码> --output <新的构建目录>
```

脚本执行 CMake、实际编译和 CTest；在编译前后核对源文件及地磁表，拒绝把构建期间变化的源码哈希贴到旧二进制上。表头从绑定 PX4 复制并保留上游版权。输出收据绑定库、地磁探针、表和本地源码的内容哈希。

Windows 构建和开发 Runtime 封装必须显式传入 `-NativeSensorRuntime <该目录>`。封装只复制库、探针、表和收据，不复制 CMake 缓存。桌面启动前核对完整 Runtime 清单及传感器语义；缺失、未列入清单、混入旧实现或者内容不符都拒绝运行。Linux Runtime 同时安装 Pillow，健康检查实际执行图像缩放，不能只在开发解释器里有图像依赖。

开发执行可显式使用 `DRONEDREAM_NATIVE_SENSOR_RUNTIME`；封装执行默认使用执行器同级的 `native-sensors`。起飞前只读回飞控实际地磁设置，与同表探针结果匹配后再继续，不修改已启动估计器以追赶真值。

## 图像配对与生命周期

相机和原生状态保留各自原始接收时间。在有界历史内选择最新且具有合格位姿配对的独立图像；50 ms 配对界和 250 ms 新鲜度界不扩大。位置误差、运动和旋转投影误差合并保守计算；转向时优先使用仍新鲜且误差在原预算内的配对，不能强行接受最新但不可靠的帧。没有合格帧时执行既有制动/保持规则。

正常完成运动后、切入降落前，执行器捕获带轨迹哈希的感知状态收据；只接受当时真实新鲜、原生、无真值修正的状态。任务失败不能借这个收据改成成功。结束后关闭遥测产生的数据过期状态仍原样保留，但不覆盖先前的运动完成收据。不能向历史失败运行补写收据以使其通过；需重新执行。

## 实测边界

### 当前感知输入转换

详细研究、误差来源和本次软件验收见 [感知与状态估计研究](SENSOR_PERCEPTION_STATE_ESTIMATION_RESEARCH.md)。深度绑定读取实际 `R_FLOAT32`（gz-msgs10 枚举 13）流尺寸、行步长，完整检查原像素；图块只压缩输出数量，不再只检查一个中心像素。真实硬件无效深度不默认视为远处无障碍。RGB 输入质量检查与模型使用同一个解码函数，不把均匀彩色画面或行填充判为丰富纹理。

深度数据携带有效源像素比例，融合按同一扫描“命中优先、体素去重”更新。位置、姿态和 IMU 的原始接收时间还要通过 50 ms 一致性检查。这些修改不改变 PX4 的估计参数，也不为未知协方差补理想值。

基准必须记下解释器的实际路径。当前执行脚本的开发入口位于 Linux 用户目录 `.local/share/dronedream-autonomy/v0.1.0/venv/bin/dronedream-agent`，并不等于机器上另一套 `/opt/dronedream/venv`。本文提到的路径是内部安装布局，不是用户界面展示版本；已有旧环境测试仅保留作环境比较，不能代替当前入口的验证。本次没有更新安装的 Runtime。

2026-09-07 的 `native-teacher-geographic-smoke-20260907` 使用实际 PX4/Gazebo 完成 9.162 m 往返并确认落地，记录 2,049 个独立采集快照。起飞前实测航向 89.897°，对应部署朝向 90°。最终门槛仍因关闭后的感知过期判为失败，该记录保持失败，不能进入合格教师数据。后续重新运行验证生命周期修复。

这个短任务是传感器与教师控制检查，不是已训练策略的长任务资格。模型权重、训练环境、长任务及安装验收继续按总体架构账本执行。
