# 无人机传感器感知与状态估计

## 结论与适用范围

可靠的感知不是把传感器读数压缩成一个数组，而是保留读数的物理意义、观测时间、标定来源和不确定性，使控制器知道哪些信息可信、哪些空间仍未知。更复杂的神经网络不能弥补错用单位、时间错配、图像采样漏检或虚假的传感器质量。工程上的首要选择是修复这些可验证的信息损失，再通过独立数据集比较学习模型。

当前仿真具有六类传感器：RGB、深度、IMU、磁力计、气压计、GNSS。深度来自 Gazebo 深度相机，并非实际双目匹配；系统没有因此获得独立的激光雷达。IMU、磁场、气压和 GNSS 首先进入 PX4 状态估计；本地专家消费状态及其来源，不应重复把同一测量当作独立证据融合。

本机检查到的 PX4 为 v1.16.0。状态估计选型以该版本文档为依据，不直接移植 main 文档中的新参数。PX4 已实现带时间补偿的误差状态 EKF，估计位置、速度、姿态和传感器偏置；在外面再增加一个缺少原始时间和相关性建模的简单滤波器，可能引入额外滞后和过度自信。[^1]

本报告区分三种证明：数学与接口正确性、带已知真值的仿真实验、真实硬件测量。通过第一种不能冒充后两种。当前没有覆盖所有六类真实传感器的标定数据，不能声称厘米级真机精度、全天候可靠性或实机飞行资格。

研究后的实际实现、2,526 项完整回归、原生 C++ 测试和延迟数据见[实现与验收记录](SENSOR_PERCEPTION_ACCEPTANCE.md)。转换正确性检查通过；投影 P99 < 20 ms 的优化目标尚未稳定通过，过程中的失败证据均保留。下文的建议和阈值不能单独视为已经达到的结果。

## 实际数据与系统边界

代码依据为 `depth_projection.py`、`sensor_bridge.py`、`native_flight_state.py`、`native_state_stream.py`、`localization_evidence.py`、`forward_rgb_binding.py`、`runtime_sensor_contracts.py` 和原生仿真传感器部署代码。检查时的源提交为 `ac2e11a`；该值表示调查基线，不是软件展示版本。已存在但未完成的本地通信改动不属于此次感知方案。

| 传感器 | 当前数据形态 | 模型或控制最终使用的信息 | 不能由它独立证明的事情 |
| --- | --- | --- | --- |
| RGB | 当前显式档案为 320×180×3 字节图像；模型输入为 1×3×128×224 浮点张量 | 视觉编码、语义线索、目标外观 | 单帧 RGB 不能独立给出可靠的绝对距离；识别“路”不等于可飞 |
| 深度 | 160×120 的小端 R_FLOAT32 轴向深度图，带行步长 | 标定射线、局部障碍、可观测自由空间、几何特征 | 相机背面、遮挡后方、无效像素不是已知自由空间 |
| IMU | 三轴比力 m/s²、三轴角速度 rad/s、设备时间 | 短时姿态运动、重力补偿后的加速度、状态历史 | 加速度积分不能无限期提供无漂移的位置 |
| 磁力计 | 三轴磁场，经单位和坐标转换进入飞控 | 辅助航向和磁偏置估计 | 金属、载荷、电机电流可能改变局部磁场 |
| 气压计 | 气压 Pa，经飞控模型与其他高度信息融合 | 相对高度变化和垂向状态 | 气压不是精确的离地距离，不能直接区分楼层地面 |
| GNSS | 经纬度、高度、速度及接收机质量信息 | 全局定位与局部坐标系锚定 | 室内不保证有效；卫星数不是定位精度证明 |

飞行状态、周围空间、动态目标必须分别表示。建议状态包括位置、速度、姿态、角速度、加速度、定位不确定性；环境包括局部占据与未知区域、动态目标速度和有效期限。电池、执行器和载荷属于额外遥测/动力学输入，不应为了凑数量当作已经接入的独立传感器。

## RGB：保持几何、检查可用性、独立评估语义

图像解码必须明确 RGB/BGR/灰度布局、宽高、行步长和原始捕获时间。行填充字节不能参与画面质量计算。畸变矫正和几何投影使用相机内参；缩放图像时也必须更新焦距和主点。OpenCV 的针孔模型提供这类投影关系，但不是一个能从任意图片直接恢复真实尺度的深度模型。[^2]

现有视觉输入使用 ImageNet 归一化和固定分辨率。冻结编码器应保持这套预处理，不可以改完归一化后仍给旧权重标注兼容。Torchvision 的 LR-ASPP MobileNetV3 是可本地部署的语义分割架构；其公开参数量、数据集精度和 CPU 时间只描述官方模型与评测条件，不是本项目定制权重的性能。[^3]

源代码中的图像质量曾以抽样字节最大值减最小值估计。这种方法把颜色通道差异也当作空间细节：一张完全均匀的彩色图片可能得到满分，少数异常像素和行填充也可能影响结果。建议改为真实像素上的亮度分布、曝光端点比例和空间对比度检查，给出明确原因；这个分数只表示输入可用性，不是识别准确率，也不能证明图像未模糊或场景属于训练分布。

准确性验收应保留同一冻结图像集与标签，分别统计每类 IoU、障碍召回、误报和弱光/逆光/运动模糊分组。不能只报告整图像素准确率，因为大面积背景会掩盖细障碍的漏检。温度缩放可在独立校准集改善概率校准，但不是分布外安全保证；分布变化时需要另行评测，不能将 softmax 最大值当作通行许可。[^4][^5]

本次不在缺少独立标签的情况下重训或替换视觉骨干。先修复布局和质量边界、保持权重输入一致，把原始图像与质量绑定到同一来源。之后换模型必须按地图/路线分组留出，避免相邻视频帧随机切分造成泄漏。

## 深度：避免为了低延迟丢掉近处障碍

### 度量与标定

轴向深度 Z 和沿像素射线的欧氏距离不同。在标准光学坐标下，三维点为 `((u-cx)Z/fx, (v-cy)Z/fy, Z)`；Gazebo 相机采用前、左、上的坐标表示时，必须进行对应的轴转换。射线距离由三维向量长度得到，不能把像素深度直接当成所有视角下的径向距离。[^2]

当前虚拟相机可使用其明确的针孔 FOV 推导内参；真实相机应提供实际标定的 fx、fy、cx、cy、畸变和相机间外参。只接受完整的内参集合。原始尺寸、FOV、范围、无返回约定、像素布局和投影算法共同参与身份绑定，不能让 160×120 的数据套用 640×480 的标定摘要。

### 仿真深度与真实双目的不同

双目深度满足 `Z = fx × B / disparity`；在其他误差忽略的一阶近似下，`σZ ≈ Z² σd / (fx B)`。因此远处误差会明显增大，不能给所有距离写同一个“准确率”。低纹理、重复纹理、反射和遮挡还可能产生非高斯错误。该公式不能用于评价直接由渲染器产生的无噪声深度。[^6]

Luxonis 对机器人场景建议的配置包含左右一致性检查、子像素和不启用时间滤波的组合，但 RVC2 与 RVC4 的配置能力不同，具体预设甚至会改变输出分辨率。硬件接入时必须读回配置，不能直接复制文档示例就宣称达到性能。厂商精度实验采用受控纹理、距离和分辨率，不能外推到本项目低分辨率仿真或玻璃表面。[^6][^7]

### 保留近障碍的有界转换

检查发现固定间隔取一个中心像素存在采样盲区。160×120 图像以步长 8 采样，仅检查约 300 个像素，原始 19,200 个像素中的其他位置没有进入近障碍选择。薄柱或细边缘恰好落在中心之外时可能完全丢失。

建议扫描全部原始像素，在每个有界图块中保留最近的有效径向障碍，并保留该障碍的真实像素方向，而不是将它搬到图块中心。如果图块没有范围内命中，最多保留一个确实观测到的无命中方向。无效像素不参与自由空间推断，不能通过均值、补洞或复制邻居变成“已测量”。输出射线数量仍受图块预算控制，遍历成本随像素数增长。

这是一种保守的有损表示，不是无损重建：一个图块内有多个障碍时只保留最近者；孤立的错误近点可能造成误报和停控。它应与真实像素有效率一起记录，不能把较少射线称为整幅覆盖。反向测试必须包含离群近点，明确该方法偏向保留潜在危险，而不是声称降噪精度提升。

正无穷只有在源协议明确表示“在传感器有效范围内无命中”时才可形成自由射线。硬件无效深度通常不是这种证据。跨硬件复用时，无返回模式必须显式配置；未知、过近、过远和真正无命中应区别对待。稀疏射线之间的空间仍然未知，不能据此证明整片锥体无遮挡。

## IMU：时间、比力与偏置不能混用

加速度计测量比力，不是已经去除重力的世界加速度。必须使用与 IMU 同步的姿态完成转换；静止水平、倾斜静止、匀速和转动应分别测试。线性向量和角速度的坐标转换也不能盲目使用同一反射矩阵。ROS 的坐标与单位约定有助于明确 ENU、NED、FLU、FRD 和光学坐标的区别。[^8]

白噪声密度、每个采样值的标准差和偏置随机游走不是同一个参数。Kalibr 的离散白噪声与 `1/√dt` 相关，偏置游走增量与 `√dt` 相关；这些关系带有滤波与采样假设，不能把未抗混叠的原始数据简单抽样后照搬。[^9]

真实硬件应先进行轴向、比例因子、偏置和温度标定；相机—IMU 时间偏差及刚性外参用有足够运动激励的数据估计。OpenVINS/Kalibr 的工作流提供可实施的标定方法，但本机没有这样的实机数据，不能凭经验补一个偏置。[^10][^11]

当前应用不重新实现惯性导航，也不对已经经过飞控处理的值重复消偏置。应增加异步来源一致性检查：姿态与 IMU 虽都未过期，但两者相差很大时，用当前姿态给旧比力去重力会制造假加速度。先使用有界时间错位拒绝，保留原始时间；没有可信同步证据时不能声称完成高精度去重力。该检查是必要条件，不是对未知传输延迟的完整修正。

## 磁场、气压、GNSS：加强估计来源而非虚构精度

### 磁力计

磁场处理需要单位、轴方向、安装姿态、硬铁偏置和软铁比例校准。当前仿真已有 Gauss/Tesla 和 PX4/Gazebo 坐标转换，并根据地图地理位置生成磁场。保持这一生产路径，增加多姿态和负面测试，而不是再次添加相互竞争的坐标补偿。

真实飞机装载物品、接通大电流设备后，磁环境可能变化；“之前校准过”不是永久有效证明。应读取飞控磁创新、拒绝状态及相关日志，异常时限制依赖航向的任务，不能让网络用一个高置信度标签覆盖飞控故障。单磁力计也不能通过复制消息变成多磁冗余。

### 气压计

气压高度受天气、温度、参考压力和桨流影响，真实误差不是单纯浮点转换误差。温度补偿需要实际温度范围下的样本，PX4 支持对包括气压计在内的传感器做热补偿；软件中删除噪声不能代替这种测量。[^12]

气压有助于短时垂向估计，GNSS 或可靠外部高度可约束漂移。取货时的下洗流、门口压差、空调气流可能使读数变化，而不是真实下降。验证应同时看高度残差、创新拒绝和控制动作，避免用一个压力尖峰触发降落。当前前视深度也不是下视高度计，不可默认为它一直能看到地面。

### GNSS

GNSS 以接收机质量和飞控融合状态为准，而不是“字段里有经纬度”。必须区分无定位、质量下降、重定位和全球坐标原点变化；姿态与局部坐标只按部署时固定的变换转换，不能用 Gazebo 真值对齐每一帧。

室内学校地图的 GNSS 仿真不代表真实室内可接收卫星。室内长期自主定位需要经验证的视觉惯性、其他定位设施或额外传感器。VIO/SLAM 可作为未来外部里程计接入，必须带坐标、协方差、重定位和时钟协议。当前没有接通 VIO 时，不能将语义视觉编码叫作视觉里程计。[^1][^10]

### 估计协方差

应用已读取原生里程计的位置协方差上界。未报告交叉项时，使用对角线之和给方向无关的保守上界，不能把未知交叉项补零后当成独立。全零、非有限、非法正定性和过期证据需要拒绝；同时应注意协方差只描述估计器的模型，不自动包含所有多路径或错误标定偏差。

MAVLink 的未知协方差有专门约定，不能解读为零误差。没有不确定性证据的输入可以被记录为未知，但不能获得精细运动许可。[^13]

## 融合、延迟与控制安全

局部地图适合用带时间的占据/自由/未知证据组织。Voxblox 展示了增量 TSDF 到 ESDF 的机载规划方法，可作为未来距离场实现的参考；它不能替代动态物体跟踪，也不能把未观测区域变成安全通道。本次不将现有体素地图仓促替换为另一套引擎。[^14]

深度转换后的命中还必须在地图融合中保留下来。逐条累加同一扫描的射线，可能让相邻穿越射线把已命中的同一体素清空；仅证明“图像检测到了障碍”不够。OctoMap 的批量点云插入采用同一扫描每个体素更新一次、命中优先于自由穿越的方式，明确用于避免相互清除造成孔洞。建议在当前地图的帧融合边界采用相同原则，并测试射线顺序置换不改变结果。[^15]

对移动障碍，新的可信命中不能被历史自由空间的累加淹没。安全地图应立即撤销该位置的自由许可；这是一项保守的工程规则，而不是独立同分布测量假设下的精确概率更新。之后清除占据需要新的观测，不能靠重复读取同一帧或邻近射线数量制造置信度。

每个输入保留捕获时钟、接收时钟、来源摘要、标定摘要和有效期。模型缓存命中不能延长帧寿命。传感器注册表不应因为没有必需传感器而返回“运动就绪”；其合同应以副本保存，防止外部修改已经通过验证的标定。质量或覆盖缺失不能默认为满分。

误差必须转化为运动限制。作为工程分析，速度为 v、响应时间为 t、可验证制动减速度为 a 时，最低的理想制动距离项为 `v·t + v²/(2a)`，还需增加机体尺寸、定位/深度误差、目标运动及控制跟踪误差。该关系不是有风、有载荷和强饱和情况下的充分安全证明。提高感知帧率若增加排队，反而可能增大有效响应时间。

云端大模型继续负责自然语言、任务阶段、解释和重规划；本地模型负责短时感知及连续控制建议。传感器校准、时间和几何安全约束应在调用前后检查，不交给模型用自然语言猜测。强化学习可以优化控制与信息获取策略，但不得奖励虚报置信度、跳过传感器或将未知当自由；训练真值只能用于监督与评估，不能混入上线输入。

## 实施与验收标准

以下是本次软件边界验收，不是整机认证。阈值是针对当前实现的工程门槛，不能被表述成研究论文已经证明的产品性能。

| 板块 | 实施 | 可执行验收 |
| --- | --- | --- |
| 深度 | 全像素近障碍保留、实际像素方向、完整标定与边界校验 | 障碍跨全部采样相位测试；近障碍保留率 100%；输出落点与独立投影公式误差 < 1e-5 m |
| 无效深度 | 不把 NaN、负无穷、过近值变成自由观测；硬件无返回语义显式 | 故障矩阵中不得产生未测自由射线；全无效帧拒绝；部分帧覆盖不能为满分 |
| RGB | 行布局校验、亮度/曝光/空间质量、源身份绑定 | 均匀彩色图与填充不能产生高空间质量；旧帧重复不续期；有效纹理仍可用 |
| 状态 | 姿态、位置、IMU 原始接收时间一致性；保留未知协方差 | 时间错配拒绝；多姿态重力补偿与轴方向测试；缺失不补零 |
| 磁/压/GNSS | 沿用 PX4 已有估计，验证单位、协方差、过期/缺失边界 | 现有原生传感器、遥测、状态和融合相关回归全部通过；不修改安装 Runtime |
| 身份 | 投影档案与真实流一致；修改语义后变更特征内容摘要 | 旧标定/旧特征摘要不得获得新资格；同一流尺寸变化应拒绝 |
| 延迟 | 不新增云调用、不新增模型下载；转换负载有界 | 本机 160×120 深度投影预热后 P99 < 20 ms；分别报告更大图像，不将它们混合平均 |
| 回归 | 生产链路消费新结果，旧功能不留双默认入口 | 核心回归与新增故障测试通过；静态检查通过；证据记录命令、来源与环境 |

验收数据要区分解析构造的真值、已有飞行日志和新的真实飞行。数学夹具用于覆盖边界，小实验用于量化信息损失与转换开销，已有日志用于检查兼容性；三者都不能单独证明长距离任务成功。真实硬件精度、复杂光学材质、长期室内定位及载荷干扰仍需对应设备和独立实验。
